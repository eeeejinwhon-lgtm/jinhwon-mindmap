JINHWON MINDMAP PORTFOLIO - LOCAL VERSION

1. Install Node.js (LTS recommended).
2. Open this folder in VS Code.
3. Open Terminal in VS Code.
4. Run:
   npm install
5. Then run:
   npm run dev
6. Open the URL shown in the terminal (normally http://localhost:5173).

No Replit account or Replit AI credits are required.
